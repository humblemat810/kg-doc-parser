## Status And Evidence Rules

- `NOT STARTED`: not yet investigated.
- `REPRODUCED`: the baseline defect has been reproduced, but not fixed.
- `IN PROGRESS`: implementation or test work is underway.
- `VERIFIED`: implementation and required tests pass.
- `NOT VERIFIED`: unavailable provider, platform, or artifact prevents proof.
- `DEFERRED`: explicitly deferred with a recorded reason.
- Every `VERIFIED` item must include a commit, test name, and command or artifact.
- Every provider or strategy claim must name the actual mode or strategy.
- A final release cannot be declared while a required item is `NOT VERIFIED`.
